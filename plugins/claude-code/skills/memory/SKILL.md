# 打开记忆星环

用 shell 运行下面这条命令（它会在后台启动记忆星环服务，并在浏览器里打开）：

```bash
npx -y dsh-forget-me-not open
```

然后告诉用户：记忆星环已经在浏览器里打开了（地址是 http://127.0.0.1:7777/）。
- 滚轮拉近星光会像走马灯一样放映记忆；一直拉进中间的星核，就是像太阳系一样的脑图，太阳是 TA 的人设卡。
- 查看记忆内容需要超级管理员钥匙在登记的位置（右下角的小钥匙）。
- 把喜欢的歌拖进页面，进入记忆时会循环播放。

不要读取、复制或打印超级管理员钥匙文件的内容。
