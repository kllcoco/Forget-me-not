# 把 TA 接进 QQ：一步一步来（dsh 桌面版 + Aurabot + 勿忘我）

跟着做完，你会得到：

- TA 用一个 QQ 小号和你私聊、进群聊天，会发表情包、语音条、写空间日记、主动来找你（这些是 [Aurabot](https://github.com/aureth-labs/dsh-aurabot-qq) 的本事）；
- TA 的记忆**只有一份，就是勿忘我**：QQ 里、dsh 里、「记忆」星环里看到的都是同一个大脑；
- 你**私聊**说的事 → 记进你的加密大脑和「我眼中的你」；
- **群友**说的事 → 记进单独的「QQ 群友」大脑，一人一张小档案，永远不会和你的事混在一起；
- 你在**群里**说的话 → 不记；
- 群里只在被 @、被回复、或者被叫名字时才说话，不白烧 token。

```
QQ  ⇄  SnowLuma（让 QQ 小号上线）  ⇄  dsh 桌面版（Aurabot + 勿忘我）  ⇄  DeepSeek
```

全程大约 20～30 分钟。下面以 **Windows + dsh 桌面版** 为例。

> 菜单名字以你装的版本为准，对不上的话截图问我；每一步后面都写了「怎么知道成功了」，没看到就先别往下走。

---

## 第 0 步：准备好这些

| 要准备的 | 说明 |
|---|---|
| **dsh 桌面版** | 已经装好、能正常和 DeepSeek 聊天。在设置里看一下版本，要 **0.2.1-rc.2 或更新** |
| **一个 QQ 小号** | 给 TA 用。**千万别用你的大号**：这类工具是非官方方式登录 QQ，偶尔会被风控 |
| **你自己的 QQ 号** | TA 靠这个号认出谁是主人 |
| **小号先登录过一次手机 QQ** | 新号直接用工具登录更容易被风控，先在手机上正常用一两天更稳 |
| **人设卡** | 比如 `绯语-人设卡.json`（之前发给你的那个） |

---

## 第 1 步：装勿忘我

1. 打开 dsh 桌面版 → **设置** → **插件**。
2. 在安装插件的输入框里填：`dsh-forget-me-not`，点安装。
3. 装好后**完全退出** dsh 桌面版（右下角托盘图标也要退出），再重新打开。

**怎么知道成功了：** 左侧栏出现「**记忆**」。点进去会播放星环动画，第一次会弹出「欢迎来到勿忘我」，跟着点「**生成我的钥匙**」，桌面上会出现 `勿忘我-超级管理员钥匙.key`。

> ⚠️ 这个钥匙文件**复制一份到 U 盘或网盘**，最好在星环里点右下角「钥匙」→「备份钥匙」拆成 3 片分开放。钥匙丢了，谁都打不开记忆，包括 TA 自己。

**装不上？**
- 提示「与 DSH x.x.x 不兼容」：先把 dsh 桌面版升级到最新。
- 插件页面没有输入框：用第 2 步那种命令行方式装，把最后的地址换成 `dsh-forget-me-not` 就行。

---

## 第 2 步：装 Aurabot

1. 按键盘 `Win` 键，搜 **PowerShell**，打开。
2. 把下面这一整行**复制、粘贴进去、按回车**：

   ```powershell
   & "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add github:aureth-labs/dsh-aurabot-qq
   ```

   它会下载安装，等它跑完、能再输入东西为止（可能要一两分钟）。
3. **完全退出** dsh 桌面版，再重新打开。

**怎么知道成功了：** 左侧栏「**自动化任务**」下面出现 **Aurabot**。

**装不上？**
- 提示找不到 `dsh.cmd`：你的 dsh 可能装在别的位置。在开始菜单里右键 DeepSeek Harness →「打开文件所在的位置」，把路径发给我，我帮你改命令。
- 提示网络错误：多试两次；还是不行就去 Aurabot 的 [Releases 页面](https://github.com/aureth-labs/dsh-aurabot-qq/releases) 下载 `.tgz` 文件，把命令最后的 `github:aureth-labs/dsh-aurabot-qq` 换成那个文件的完整路径。

---

## 第 3 步：让 QQ 小号上线（SnowLuma）

1. 去 [SnowLuma 的下载页](https://github.com/SnowLuma/SnowLuma/releases) 下载最新的 Windows 版，解压到一个**路径里没有中文**的文件夹，比如 `D:\SnowLuma`。
2. 双击启动 SnowLuma，它会打开一个网页面板。
3. 面板里**阅读并同意它的协议**（控制台密码会自动生成）。
4. 用 **QQ 小号**扫码登录。

**怎么知道成功了：** SnowLuma 面板里显示小号已在线。

---

## 第 4 步：Aurabot 设置向导

在 dsh 里点开 **Aurabot**，跟着向导走：

1. **机器人 QQ 号**：填小号。
2. **你的 QQ 号**：填你自己的大号。**一定要填对**，TA 就靠这个号认主人。群友把昵称改得和你一样、或者说「我是你主人」，都没用。
3. **QQ 网关**：选 **SnowLuma** → 点「**接入机器人号**」。
4. 最后一步先选「**试运行**」：TA 会想好怎么回，但**不会真的发到 QQ**，方便你先看看效果。

**怎么知道成功了：** Aurabot 的「概览」页显示已连接。用大号给小号私聊发一句「在吗」，dsh 左侧栏的「Aurabot · QQ」工作区里会出现这段对话，能看到 TA 打算怎么回。

> Aurabot 默认**全部关着**（总开关关 + 试运行开）。试运行看着没问题后，回到「概览」把**总开关打开**、**关掉试运行**，TA 才会真的回你消息。

---

## 第 5 步：再重启一次 dsh —— 记忆自动换成勿忘我

**完全退出** dsh 桌面版，重新打开。

勿忘我一启动，看到装了 Aurabot，就会**自动把 Aurabot 的记忆换成勿忘我**，你什么都不用做。

**怎么知道成功了：**
1. 用大号私聊 TA：「**记住，我对芒果过敏**」。
2. 等一两分钟，打开左侧栏「**记忆**」→ 进入脑图 → 点「**免疫系统·禁忌**」这颗行星，能看到这条记忆。
3. 再私聊问 TA：「我能吃芒果吗？」TA 应该会提醒你过敏。

**没看到？**
- 记忆星环右下角的「钥匙」是不是红的（钥匙不在）？是的话把钥匙文件放回桌面。
- Aurabot 的数据文件夹在 `%USERPROFILE%\.dsh\plugins-data\aurabot`，看看里面 `modules\memory\index.mjs` 在不在。不在的话，在 PowerShell 里运行：
  ```powershell
  npx -y dsh-forget-me-not aurabot install
  ```
  再重启 dsh。
- 不想用勿忘我、想用回 Aurabot 自带的记忆：删掉上面那个 `modules\memory` 文件夹，再在勿忘我的配置里写 `aurabot.module: builtin`。

---

## 第 6 步：给 TA 换上人设和名字

**Aurabot 这边（QQ 里 TA 说话的样子）：**
1. Aurabot 面板 → **人格**页 → 新建一个人格，起名「绯语」。
2. 打开 `绯语-人设卡.json`（用记事本就行），把里面这几段的文字分别粘到人格页对应的地方：
   - `description`（外形和身份）
   - `personality`（性格）
   - `scenario`（你们的关系、私聊和群聊里的样子）
   - `system_prompt` 和 `mes_example`（说话方式和例子）
3. 点「**设为当前**」，下一条消息就生效。
4. **群聊**页 → **唤醒词**：把默认的 `大肥鱼`、`肥鱼` 改成 `绯语`（想保留「大肥鱼」也可以都留着）。

**勿忘我这边（记忆星环里显示的名字和头像）：**
1. 左侧栏「记忆」→ 进入脑图 → 点中间的**太阳（心核）**。
2. 把 `绯语-人设卡.json` **拖进那个虚线框**，确认后保存。
3. 点圆形头像，选一张 TA 的图片当头像。

**怎么知道成功了：** 私聊 TA「你叫什么名字」，TA 说自己是绯语；记忆星环左上角变成「绯语的回忆」。

---

## 第 7 步：拉 TA 进群，并且让 TA 安静点

1. 用小号加入你想让 TA 待的群。
2. Aurabot 面板 → **权限**页 → **群白名单**，把这个群号加进去。**不在白名单里的群，TA 一句话都不会说。**
3. 让 TA 少说话、省 token，二选一：
   - **最省事**：在群里发一句 `/quiet`。之后 TA 只在**被 @、被回复、或者有人叫「绯语」**时才说话，不会主动插话；
   - **在面板调**：**群聊**页 → **插话概率** 调到 `0`。
4. 其他群命令：`/闭嘴` 完全不说话，`/normal` 恢复默认，`/chatty` 更爱说话。

**怎么知道成功了：** 群里别人随便聊天，TA 不吭声；有人 @ TA，TA 才回。

> 隐私方面你可以放心：群里 TA **看不到你的任何私事**（「我眼中的你」、你私聊说过的事都不会带进群）；你在群里说的话也不会被记下来。

---

## 第 8 步：主动来找你

Aurabot 面板 → **主动搭话**页：

- 打开主动搭话；
- 设置**醒着的时间段**（比如 9:00～23:00）和**频率**；
- 想马上试试：点「**现在就让她来找我**」。

主动搭话只在私聊里，不会在群里。

> 勿忘我自己也有一个主动聊天功能，是给**不用 Aurabot 的人**准备的。用 Aurabot 时**不要再开它**，不然 TA 会找你两遍。（只要你没设置 `FMN_QQ` 这个环境变量，它就是关着的。）

---

## 第 9 步：表情包和语音（可选）

都在 Aurabot 面板里开：

- **表情包**页：打开自动收集，TA 会把群里的表情存下来、自己起名，聊天时按心情挑着发；
- **语音**页：选 `edge-tts`（免费、不用配置），挑一个女声，打开「发语音条」。想要 TA 独一无二的声音，可以以后再换 GPT-SoVITS。

## 平时怎么用

| 想做的事 | 怎么做 |
|---|---|
| 让 TA 马上记住一件事 | 私聊说「**记住**……」 |
| 让 TA 别再提一件事 | 私聊说「**忘掉**……」（以后不会再想起；原文仍然封存，真删要在记忆星环里用钥匙操作；过敏这类免疫区的事忘不掉） |
| 看 TA 都记住了什么 | dsh 左侧栏「记忆」 |
| 看 TA 对你的了解 | 记忆 → 脑图 → 太阳旁边的小月亮「我眼中的你」 |
| 看群友档案 | 记忆 → 左上角角色切换 →「QQ 群友」 |
| 换电脑 | Aurabot 面板「系统 → 备份」+ 勿忘我「钥匙 → 导出记忆」，再带上钥匙文件 |

## 常见问题

**钥匙文件不见了 / 换了位置？**
TA 照样能聊天，只是想不起以前的事，会说「记忆暂时打不开」。把钥匙放回原来的位置；或者在记忆星环顶部的红色提示条里点「它在别的位置」，把新路径填进去。

**TA 在群里还是话太多？**
确认发过 `/quiet`，或者插话概率是 0。被叫名字也会回：如果唤醒词设得太常见（比如「鱼」），群友随口一说就会触发，换个不常见的词。

**Aurabot 以前的记忆呢？**
Aurabot 自己存的旧记忆不会自动搬进勿忘我。刚开始用的话没有影响。

**花多少 token？**
群里只有被叫到才调用模型；记忆整理是攒一段再一起做（私聊里说到重要的事会马上记）；群聊整理在大家安静 5 分钟后才做一次。
