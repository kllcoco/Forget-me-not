# 勿忘我 · Forget-me-not

> 她会想起，也会遗忘。
> 把她留在时间里的痕迹，延长得再久一些。

**勿忘我**是给 AI 用的长期记忆大脑，任何 LLM 都能接。它按人脑的「多层记忆架构」来组织记忆：

- **AI 自己总结后写入**：对话里值得记住的事，由模型自己总结成一两句话，写进对应的脑区。
- **封存**：记忆一写进去就被加密。AI 只能**写入新记忆**和**回想**，不能修改、不能删除，也读不到原始数据。
- **超级管理员**：只有你凭密码才能查看、修改或删除记忆。
- **会遗忘**：不重要的记忆会随时间淡去，被想起越多次记得越牢；淡忘的记忆遇到强烈的线索还能被重新想起。
- **记忆星环**：3D 莫比乌斯 ∞ 星环，每一颗小星光就是一段记忆。开场有星环成形的过场动画；拉近之后，星光会像走马灯一样逐个放映，重要的记忆旁边会弹出那一刻的画面。

---

## 大脑的分区

| 脑区 | 存什么 |
|---|---|
| 长期记忆库 | 值得长久记住的事件与事实、约定 |
| 边缘系统·情绪 | 带强烈情绪的时刻，对人或事的感受 |
| 神经图谱 | 人物与关系 |
| 生活回路 | 作息、习惯、口味、喜好 |
| 工作记忆 | 这几天的临时安排，很快会淡忘 |
| 语言中枢·表达 | 喜欢的称呼、语气、彼此的暗号 |
| 内省·反馈 | AI 自己的反思与教训 |
| 视觉皮层 / 听觉皮层 | 看过的画面、听过的歌 |

还有四个「器官」不存记忆，只在星环里显示数据流动：**语言输入 → 海马体·写入 → 各脑区**、**大脑中枢·检索**（回想时发出光束）、**代谢·治理**（让记忆淡去）。

记忆类型：事件、事实、偏好、技能、教训、反思。重要性从 0 到 1。

## 三种接法

### ① DeepSeek Harness（dsh）插件

装好之后，dsh 左侧栏会多一个 **「记忆」** 入口。点进去先播放星环成形的过场，然后就能缩放、浏览记忆。dsh 里的 AI 会自动拿到三个记忆工具，系统提示词里也会带上记忆的使用说明。

```bash
# 从本地目录安装（需要 pnpm 10+，dsh >= 0.2.2-rc.1）
git clone https://github.com/kllcoco/Forget-me-not.git
dsh plugin --profile web add ./Forget-me-not
dsh web
```

第一次打开「记忆」时，先设定**超级管理员密码**。设定之前，AI 写不进记忆。

> 发布到 npm 以后，就可以直接 `dsh plugin --profile web add forget-me-not`。

### ② 任何支持 MCP 的客户端（Claude Desktop / Claude Code / Cursor / Cherry Studio …）

```json
{
  "mcpServers": {
    "forget-me-not": { "command": "npx", "args": ["-y", "github:kllcoco/Forget-me-not", "mcp"] }
  }
}
```

也可以用远程 MCP（streamable HTTP）：`http://127.0.0.1:7777/mcp`。

### ③ 任何能调用函数的模型（OpenAI / Gemini / GPTs / Dify / Coze …）

先启动记忆星环服务：

```bash
npx github:kllcoco/Forget-me-not serve     # 打开 http://127.0.0.1:7777
```

| 用途 | 地址 |
|---|---|
| OpenAPI（GPTs Actions、Dify、Coze） | `GET /openapi.json` |
| 各家函数格式 | `GET /api/tools?format=openai\|anthropic\|gemini\|mcp` |
| 直接调用工具 | `POST /api/tools/<工具名>`，请求体是 JSON 参数 |
| 给模型的使用说明 | `GET /api/protocol`（可以放进 system prompt） |

## AI 能用的工具

| 工具 | 作用 |
|---|---|
| `memory_wake` | 醒来：看看每个脑区有多少记忆，以及最重要、最近的几段。每次对话开始先调用。 |
| `memory_remember` | 把自己总结好的一段记忆封存进某个脑区：内容、脑区、类型、重要性、情绪、标签、发生时间；重要的记忆可以带 `image`（链接 / base64 / 本地路径）或 `image_prompt`（描述那一刻的画面）。 |
| `memory_recall` | 用线索回想。被想起的记忆会更牢，淡忘的记忆遇到强线索会复苏。 |

AI **没有**修改和删除的工具。写错了，它只能再写一条更正的记忆。

## 封存是怎么做到的

可以把它想成一个邮筒：谁都能往里投信，只有拿钥匙的人能打开。

1. 设定密码时，生成一对 X25519 密钥。私钥用 `scrypt(密码)` 派生的密钥加上 AES-256-GCM 锁起来再存盘，明文私钥从不写到磁盘上。
2. AI 每写一段记忆，都用一把一次性密钥和公钥协商出加密密钥（ECDH + HKDF + AES-256-GCM）。所以**写入不需要密码**。
3. 磁盘上只有记忆的「外形」是明文：脑区、时间、重要性，用来画星环。内容、标题、情绪、标签、配图，以及回想时用的线索，**全部是密文**。就算 AI 有读文件的权限（dsh 的 agent 能跑 shell），读到的也只是乱码。
4. **回想**需要私钥，所以要超级管理员先输入密码**唤醒**大脑。唤醒后私钥只留在这个进程的内存里，进程重启后大脑就重新沉睡。
5. 在星环里查看内容，也要超级管理员密码。点「封存中」解封，点「已解封」重新封存（大脑仍然醒着，AI 还能回想）。密码连续输错会被暂时锁定。
6. 修改、淡忘、彻底删除，只有超级管理员能在星环的卡片上操作。

⚠️ **忘了密码，记忆就再也打不开了**，连 AI 自己也打不开。

数据目录：独立运行时是 `~/.forget-me-not/`，dsh 里是 `$DSH_HOME/forget-me-not/`，也可以用环境变量 `FMN_HOME` 指定。

```
vault.json      公钥 + 被密码锁住的私钥
memories.json   记忆（外形明文，内容密文）
events.jsonl    大脑活动日志（线索加密）
images/*.bin    加密后的配图
```

## 遗忘曲线

每段记忆有一个**强度**，随时间按指数衰减（类似艾宾浩斯遗忘曲线）：

- 越重要，衰减越慢：普通脑区的稳定期是 `2 + 90 × 重要性²` 天，工作记忆只有 `0.5 + 2 × 重要性` 天；
- 每被想起一次，稳定期增加 50%（最多算 10 次）；
- 强度低于 0.12 就会被**淡忘**（归档）。重要性 ≥ 0.85 的记忆永远不会被淡忘；
- 淡忘的记忆在星环里会变暗变灰。回想时线索的相似度 ≥ 0.3，它就会**复苏**。

回想排序：`0.65 × 相似度 + 0.15 × 重要性 + 0.2 × 当前强度`。相似度用的是零依赖的中英文字词哈希向量。

## 记忆星环怎么玩

- **开场**：一颗星核亮起，星尘从四面八方飞来，沿着 ∞ 绕一圈，连成莫比乌斯星环。双击屏幕、按任意键或点右下角「跳过」都可以跳过。
- **缩放**：滚轮或双指缩放，右侧也有缩放条。离得越近，星光越显出各自脑区的颜色。
- **走马灯**：靠近星环停一会儿，就会从最近的那颗星开始逐个放映。镜头沿着星环滑行，记忆卡片跟着星光弹出；重要的记忆停留得更久，并配上那一刻的画面。没有真实图片的记忆，会按 `image_prompt` 画一幅「记忆画」（离线生成，同一段记忆永远是同一幅画）。也可以点左侧的脑区，或点任意一颗星。键盘 ← → 切换，空格暂停，Esc 离开。
- **实时动画**：AI 写入记忆时，一颗彗星从「语言输入」飞到「海马体」，再飞进对应脑区，新星诞生。回想时，「大脑中枢」向被想起的星发出光束。淡忘时，星光像灰烬一样落下。复苏时会迸出金色火花。
- **搜索**（超级管理员）：右上角「想起……」。

## 开发

```bash
npm test                                   # 单元测试（node:test，零依赖）
FMN_PASSWORD=******** node bin/forget-me-not.js seed --reset   # 放入一年份的示例记忆（全部虚构）
node bin/forget-me-not.js serve
```

- 运行时零依赖，只需要 Node 20 或更高版本。Three.js r170 放在 `web/vendor/` 里，可以离线使用。
- `lib/core/`：大脑、加密、工具定义、HTTP、MCP。独立服务和 dsh 插件共用这一份。
- `lib/index.js` / `lib/client.js`：dsh 插件的 Host 端和浏览器端。
- `web/`：记忆星环（Three.js + 自写着色器 + Bloom）。
